# Image Processing Application

A C++ image processing application developed as part of the CS213 assignment at Cairo University, Faculty of Computers and Artificial Intelligence under the supervision of Dr. Mohammad El-Ramly.

## Features

The application supports multiple image processing filters, including:

* Grayscale
* Black and White
* Inversion
* Rotation
* Edge Detection
* TV Effect
* And more!

##Youtube showcase: https://youtu.be/cDtvcSgCsyc?si=4gxkSNoGFzZ9kKt3.

## Requirements

* C++ compiler
* Qt Creator (for the GUI version, if applicable)

## How to Run

1. Clone or download this repository.
2. Open the "OopFiltersProjectGUI" folder in the project using Qt Creator.
3. Open the `CMakeLists.txt` file.
4. Configure the project using a compatible compiler.
5. Build and run the application.

OR

1- open the project using VS code.
2- open Final Project.cpp
3- Run by writing:
g++ "FinalProject.cpp" -o program.exe 
then :
.\program.exe

## Project Structure

* `main.cpp` – Main application entry point.
* `Filters/` – Contains the image processing filter implementations.
* `Images/` – Contains sample images.
* `CMakeLists.txt` – CMake project configuration.
